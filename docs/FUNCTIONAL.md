# 功能文档

本文档面向使用者、验收人员和后续产品维护者，描述系统当前实现的业务能力。

## 角色与入口

| 角色 | 默认账号 | 主要入口 | 能力范围 |
| --- | --- | --- | --- |
| 超级管理员 | `admin / Admin@123` | `/admin/login` | 后台管理、题库/题目/分类、用户、角色权限、登录日志、学员统计 |
| 学员 | `student / Student@123` | `/login` | 练习、模拟考试、错题本、答题历史、改密 |
| 教练 | `teacher / Teacher@123` | `/admin/login` | 查看学员统计、题库题目读权限、登录日志读权限 |

首次运行需执行 `pnpm db:seed` 写入默认角色、权限、账号、内置题库和示例题。
系统内置 5 个角色：`super_admin`、`admin`、`teacher`、`student_strict`、`student_normal`。默认 `admin` 账号绑定 `super_admin`，演示学员绑定 `student_normal`，演示教练绑定 `teacher`。

## 学员端功能

### 练习入口

路径：`/exam`

- 展示可用题库与题量。
- 支持顺序练习、随机练习、章节练习、模拟考试、错题重做。
- 已有进行中会话时显示“继续”入口，并提供放弃当前会话的操作。
- 进入页面时会兜底结算已过期的模拟考试会话。

### 答题模式

| 模式 | 行为 |
| --- | --- |
| 顺序练习 | 按题目创建时间顺序生成题目快照，逐题提交后给出反馈 |
| 随机练习 | 创建会话时随机打乱题目顺序，快照在会话生命周期内固定 |
| 章节练习 | 根据所选分类及其子分类筛题，按稳定顺序答题 |
| 模拟考试 | 按题库配置抽题，限时答题，答题中不展示答案解析 |
| 错题重做 | 抽取当前学员未掌握错题，按最近答错时间倒序练习 |

### 答题页

路径：`/exam/session/[attemptId]`

- 展示题干、题型、题号、选项和进度。
- 支持单选、多选、判断题。
- 普通练习提交后展示正确/错误、正确答案、解析和选项高亮。
- 提交时记录本题耗时，服务端会限制异常耗时值。
- 提交的题目必须属于当前会话题目快照，否则会被拒绝。
- 模拟考试倒计时，并通过 `sendBeacon` 在关闭页面时兜底通知服务端放弃；正常提交表单时不会触发误放弃。
- 题图加载失败时显示可访问的“图片加载失败”占位，不阻断答题。
- 支持主动交卷和放弃练习。

### 结果与历史

- `/exam/session/[attemptId]/result`：展示状态、得分、正确数、用时和逐题解析。
- `/exam/history`：展示已完成或已放弃会话。
- `/exam/history/[attemptId]`：查看单次历史详情。
- `/exam/wrong`：查看错题，按题库和掌握状态筛选，支持标记/取消掌握。

## 后台功能

### 后台工作台

路径：`/admin`

- 根据当前用户权限展示后台菜单。
- 学员访问后台会被重定向到学员端。
- 后台人员访问学员练习页会被重定向到后台。

### 题库管理

路径：`/admin/banks`

- 新建或更新题库。
- 查看题库题量。
- 内置题库不可删除。
- 已有关联题目的题库不可删除。

### 分类管理

路径：`/admin/categories`

- 创建全局分类。
- 支持父子分类。
- 同级分类名不可重复。
- 删除父分类前必须先删除子分类。

### 题目管理

路径：`/admin/questions`

- 按题库、题型、关键字筛选题目。
- 新建题目：`/admin/questions/new`
- 查看题目详情：`/admin/questions/[id]`
- 支持题目分类和标签。
- 题型校验覆盖单选、多选、判断题。
- 已被答题记录或错题本引用的题目不可删除。

### 批量导入

路径：`/admin/questions/import`

- 支持粘贴 JSON。
- 支持上传 Excel。
- 支持下载 Excel 模板：`/admin/questions/import/template`
- 流程为“预览校验 -> 确认导入”。
- 预览显示可导入数量、跳过数量和非法行错误码。
- 分类按名称复用或创建。
- 非法行不会影响合法行导入。
- Excel 的 `categories` 和 `tags` 多值列使用 `|` 分隔。

### 用户管理

路径：`/admin/users`

- 创建用户。
- 指定角色。
- 设置用户状态：`ACTIVE`、`FROZEN`、`DISABLED`。
- 重置密码。
- 只有超级管理员可以创建超级管理员账号。
- 只有超级管理员可以修改超级管理员账号状态或重置其密码。
- 冻结用户恢复为 `ACTIVE` 时，会清除原登录 IP 和设备指纹基线，便于重新建立严格登录校验。

### 角色权限

路径：`/admin/roles`

- 查看角色权限。
- 超级管理员可编辑非超级管理员角色的权限。
- 权限变更后用户需重新登录才能刷新会话内权限缓存。

### 登录日志

路径：`/admin/login-logs`

- 查看登录记录。
- 支持按用户名、IP、设备关键字检索。
- 记录成功/失败、原因、IP、设备和时间。

### 学员统计

路径：

- `/admin/student-stats`
- `/admin/student-stats/[userId]`

能力：

- 查看学员列表、练习次数和最近练习时间。
- 查看单个学员汇总、平均正确率和答题历史。
- 支持按题库、模式筛选。

## 安全与权限

- 使用签名 Cookie 会话。
- RBAC 权限码由种子数据初始化。
- `super_admin` 拥有所有权限。
- 普通后台管理员不能管理 `super_admin` 账号，也不能给新用户分配 `super_admin` 角色。
- 严格学员角色开启异地登录冻结：同账号在不同 IP 或不同设备指纹登录会被冻结。
- 缺失设备指纹时拒绝登录并记录日志。
- 错题掌握/取消掌握需要 `wrong:manage` 权限。
- Server Component 和 Server Action 均会按权限校验。

## 数据导入格式

### JSON

支持顶层数组：

```json
[
  {
    "type": "SINGLE",
    "content": "题干",
    "optionA": "选项A",
    "optionB": "选项B",
    "answer": "B",
    "categories": ["交通标志"],
    "tags": ["易错"]
  }
]
```

也支持对象包装：

```json
{
  "questions": []
}
```

### Excel

模板列：

```text
type, content, imageUrl, optionA, optionB, optionC, optionD, optionE, optionF, answer, categories, explanation, tags
```

规则：

- `type`：`SINGLE`、`MULTI`、`JUDGE`
- `answer`：单选用单个字母，多选用升序字母串，判断用 `T` 或 `F`
- `categories` / `tags`：多个值用 `|` 分隔
- 若答案引用的选项列为空，该行会被标为非法
